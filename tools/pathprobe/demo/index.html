File format and limits

{"durations":{"plan":10,"search":80,"fetch":40,"merge":10},
 "edges":[["plan","search"],["plan","fetch"],["search","merge"],["fetch","merge"]]}


Each edge is a prerequisite followed by its dependent task. Use nonnegative integer durations in one unit throughout. The file limit is 512 KiB, with up to 512 tasks and 4,096 edges. Each path must fit JavaScript’s safe integer range. The Python package accepts larger runs.
